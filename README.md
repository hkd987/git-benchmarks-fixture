# git-benchmarks fixture

This repository is a scratch target for the
[git-benchmarks](https://github.com/hkd987/git-benchmarks) harness. It exists so
the harness has somewhere to push a generated repository and time the result.

Branches named `bench/*` appear during a run and are deleted when it finishes.
Nothing here is meant to be read by a human, and nothing here is kept.
